- **Retained terminal exit evidence after normalization failure.** Terminal runs now preserve an independently observed code or signal exit as process evidence when VT normalization rejects the final output, while the run remains honestly failed and records the bounded normalization diagnostic. This includes startup failures: `StartFailed` gains an optional `observation` field, absent by default and accepted only after complete negotiation with initial-time exited-process evidence. Existing positional construction remains compatible because the field is appended after `diagnostics`; consumers that inspect `StartFailed` may now read `result.observation` and recorders emit it before `run.failed`.
