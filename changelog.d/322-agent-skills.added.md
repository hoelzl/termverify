- **Agent skills (#322).** Six proven procedures are packaged under
  `.agents/skills/` — `changelog-fragment`, `parallel-worktree`,
  `handover-lifecycle`, `adversarial-review`, `cut-release`, and
  `doc-gardening`. Each `SKILL.md` carries a one-line `description` of when to
  use it and links to the developer-guide page that holds the rules instead of
  copying them; `AGENTS.md` points to the folder, and
  `scripts/validate_agent_docs.py` checks each skill's `name` and
  `description`.
