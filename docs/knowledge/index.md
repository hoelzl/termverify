# TermVerify Knowledge Bundle

This directory is an [Open Knowledge Format (OKF) v0.1](https://github.com/GoogleCloudPlatform/knowledge-catalog/tree/main/okf) bundle. It provides progressive disclosure for humans and coding agents.

## Foundation

- [Product vision](product-vision.md) — scope, users, non-goals, and the
  single source for capability that is planned but does not exist yet.
- [Architecture](architecture.md) — boundaries, adapters, and package model.
- [Verification model](verification-model.md) — evidence layers and oracle
  types, marking the ones TermVerify supplies no machinery for yet.
- [Evidence governance](evidence-governance.md) — accepted redaction, capture,
  and baseline-approval controls.
- [Protocol](protocol.md) — the `termverify.transcript/v1` transcript
  contract: where acceptance authority lives, a summary, and its topic pages.
- [Control protocol](control-protocol.md) — the `termverify.control/v1`
  live wire protocol for JSONL-subprocess subjects.

## Reference

- [Glossary](glossary.md) — core vocabulary and the historical names that
  older decision records use.

## Navigation rule

Read this index first, then open only the concepts needed for the current change. The files are durable design knowledge, not a task tracker; use GitHub and Git for volatile project state.
